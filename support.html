자주 묻는 질문

카메라나 마이크가 켜지지 않아요

폰 설정 → 같공 → 카메라·마이크 권한이 켜져 있는지 확인해 주세요. 처음 스터디룸에 들어갈 때 권한을 거절하면 그 뒤로는 다시 묻지 않습니다.

스터디룸에 어떻게 참여하나요?

친구에게 초대 코드를 받아 홈 화면의 스터디룸에서 입력하면 들어갈 수 있습니다. 직접 방을 만들면 코드가 생기고, 방 화면에서 공유 버튼으로 친구에게 보낼 수 있습니다. 초대 코드는 아는 사람에게만 알려주세요.

잠깐 자리를 비우고 싶어요

스터디룸에서 커튼을 치면 화면이 가려집니다. 방에서 나가지 않아도 되고, 돌아와서 다시 걷으면 됩니다.

알림이 오지 않아요

폰 설정 → 같공 → 알림이 켜져 있는지 먼저 확인해 주세요. 공부 리마인더는 앱 안에서 마이 → 설정(톱니 아이콘) → 공부 리마인더에서 켜고 시각을 고를 수 있습니다.

화면을 어둡게 쓰고 싶어요

마이 → 설정 → 화면 테마에서 시스템·라이트·다크 중에 고를 수 있습니다. 고르는 즉시 앱 전체에 반영되고, 다음에 켤 때도 그대로 유지됩니다.

불쾌한 사용자를 만났어요

해당 사용자를 신고하거나 차단할 수 있습니다. 차단하면 서로 보이지 않습니다. 차단한 사람은 마이 → 설정 → 차단한 사용자에서 확인하고 풀 수 있습니다. 자세한 기준은 신고·차단 및 제재 정책을 참고해 주세요.

스터디캠 영상이 녹화되나요?

아니요. 영상과 음성은 서버에 저장되지 않습니다. 같은 방에 있는 사람에게 실시간으로 전달될 뿐이고 녹화 기능이 없습니다. 자세한 내용은 화상 녹화·녹음 정책에 있습니다.

계정을 삭제하고 싶어요

마이 → 내 프로필 → 맨 아래 회원 탈퇴에서 직접 삭제할 수 있습니다. 앱을 지우는 것만으로는 계정이 삭제되지 않습니다. 절차와 삭제되는 데이터는 계정 삭제 요청 페이지에 정리해 두었습니다.

광고가 나오는데 없앨 수 있나요?

현재 같공은 무료이며 화면 아래에 배너 광고가 표시됩니다. 광고 제거 상품은 아직 제공하지 않습니다.
